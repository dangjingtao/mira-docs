MiraDocs 把内容、构建和发布保持在同一个仓库里。

它首先服务三个场景：

- 产品和工程文档；
- 面向外部的博客或轻量 CMS；
- 从结构化 Markdown 生成的项目门户。

## 为什么从 Git 开始

Git 天然提供版本、审阅、回滚和协作。MiraDocs 不重新发明这些能力，而是把内容协议和展示层补齐。

## Skill 如何参与

正式的 MiraDocs Skill 安装在 UIChat Mira。它只操作稳定的内容、配置和发布协议，不直接修改 React 页面实现。
